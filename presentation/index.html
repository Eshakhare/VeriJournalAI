The 9-Stage Asynchronous Verification Contract

Phase I: Ingress & Defenses
1 validating_input PayloadLimit

Enforces schema contracts, Idempotency-Key headers, and sliding-window rate limits per UID.

2 checking_url Safe Browsing

Google Safe Browsing v4 API checks + domain impersonation heuristics (typosquatting, lookalike domains).

3 extracting_content SSRF Shield

Hardened SSRF fetcher: pre-resolves DNS, blocks private RFC 1918, loopback, and Cloud metadata IPs.

Phase II: AI & Evidence RAG
4 extracting_claims Gemini Vertex

5 checking_fact_checks Fact Check API

Queries Google Fact Check Tools API v1alpha1 across global accredited rating agencies (PolitiFact, AFP, etc.).

6 retrieving_evidence Search RAG

Generates search queries, retrieves multi-angle sources, extracts exact citations, and classifies stance.

Phase III: Forensics & Storage
7 analyzing_media Vision & EXIF

Pillow magic bytes, EXIF GPS privacy strip, Cloud Vision web detection (earliest observed web matches).

8 building_timeline Chronology

Assembles event occurrences, media discovery history, and publication dates into unified timeline.

9 saving_report Firestore Subcollections

Durable storage under users/{uid}/journalEntries/{id} with owner-only access rules.

DEFENSE-IN-DEPTH SECURITY MODEL

Why Enterprises & Newsrooms Trust VeriJournal AI

Zero Client Secrets

No Gemini API keys, Google Cloud service credentials, or third-party tokens are packaged in the web client. All AI generation is performed server-side via Cloud Run using Google Cloud Application Default Credentials (ADC).

Strict Tenant Isolation

Authenticated UID is derived exclusively from verified Firebase ID tokens. Journal subcollections are partition-locked under users/{uid}/journalEntries/.... Cross-tenant access attempts return 404 to avoid ID probing.

SSRF & DNS Rebinding Shield

Custom hardened HTTP fetcher pre-resolves hostnames before connecting, strictly rejecting RFC 1918 private subnets, loopback addresses, and cloud instance metadata (169.254.169.254) on all redirects.

EXIF / GPS Privacy Stripping

Precise GPS coordinates and camera serial numbers are automatically stripped during Stage 7 media analysis. Location coordinates are never passed to the LLM and only stored if the user explicitly opts in.

Data-Only Prompt Envelopes

Scraped web content and search snippets are isolated inside strict <untrusted_input> envelopes, neutralizing indirect prompt injection and adversarial jailbreak attacks.

GDPR Compliance & Erasure

Immediate cascaded erasure via DELETE /api/v1/journal/entries/{id} purges all claims, evidence, media assets, and chat logs. Full export available via POST /api/v1/me/export.
